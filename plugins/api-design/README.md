# API Design

Design new APIs, evolve existing contracts, and check compatibility using Sergey Konstantinov's official guidance accompanying *The API*.

## Install

```bash
claude plugin marketplace add dimonb/skills
claude plugin install api-design@dimonb-skills
```

```bash
codex plugin marketplace add dimonb/skills
codex plugin add api-design@dimonb-skills
```

Ask to design an API, evolve a contract or review a change for compatibility. The skill loads detailed references as needed. It produces concrete contracts, consumer workflows and failure/recovery decisions; it does not require a CLI or network access to read its bundled guidance.

The plugin is independent of ship, shipyard and council. See [provenance](skills/api-design/references/provenance.md) and [MIT license](LICENSE). The book is linked, not bundled. This adaptation is not an endorsement by the original author.
